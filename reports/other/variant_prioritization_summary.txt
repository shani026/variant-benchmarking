VARIANT DISCREPANCY SCORING METHODOLOGY:
---------------------------------------------
PRIORITY TRANSCRIPT-BASED PRIORITIZATION:
HGVS concordance on priority transcript drives prioritization.
MANE-first transcript selection ensures clinical standard compliance.
VUS and missing data de-prioritized (less clinically actionable).

PRIORITY CATEGORIES (4-Category System):
• CRITICAL: HGVS mismatches on priority transcript (100+ points)
            OR major clinical significance changes (Pathogenic↔Benign)
• MODERATE: Priority transcript unavailable OR moderate clinical changes (60-99 points)
• LOW: Minor changes and prediction differences (20-59 points)
• CONCORDANT: Perfect priority transcript match with identical HGVS (0 points)

PRIORITY TRANSCRIPT-BASED SCORING WEIGHTS:
• HGVS nomenclature mismatch (HGVSc): +100 points (CRITICAL)
• Pathogenic↔Benign clinical changes: +90 points (CRITICAL)
• HGVS protein mismatch (HGVSp): +50 points (CRITICAL)
• Priority transcript unavailable: +60 points (MODERATE)
• Pathogenic↔VUS changes: +40 points (MODERATE)
• Serious functional differences: +35 points (MODERATE)
• VUS↔Benign changes: +25 points (LOW)
• Gene/impact changes: +15 points each (LOW)
• Pathogenicity consensus flip (P↔B): +35 points (LOW-MODERATE)
• Pathogenicity consensus shift (±uncertain): +20 points (LOW)
• Individual predictor changes (stable consensus): +10 points (LOW)
• Missing clinical data: +5 points (minimal penalty)

TRANSCRIPT SELECTION STRATEGY:
• MANE Select transcripts (highest priority)
• MANE Plus Clinical transcripts (fallback)
• Canonical transcripts (when MANE unavailable)
• First available matching transcript (last resort)
• Same transcript used for comparison in both builds

CLINICAL EVIDENCE OVERRIDE:
• 90% score reduction for benign variants (LOW/MODIFIER + benign evidence)
• 2x score boost for pathogenic variants (HIGH impact or pathogenic evidence)
• Maintains clinical context while prioritizing HGVS concordance

RATIONALE:
HGVS nomenclature consistency is the top clinical priority for variant interpretation.
Priority transcript approach ensures same transcript compared between builds.
VUS-related changes de-prioritized as they are less clinically actionable.
This approach focuses clinical review on variants most likely to affect patient care.

DATA PROCESSING NOTES:
• Priority transcript selected using MANE-first hierarchy
• Clinical significance normalized to standard categories
• Bounded scoring prevents category inflation
