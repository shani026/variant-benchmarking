Simple Truvari Structural Variant Benchmark Report

Scope: This report uses only existing Truvari results from 04_benchmark_results/truvari/. It does not rerun Truvari, does not use RTGtools, does not use Wittyer, and does not include liftover.

1. Aim

The aim of this report is to summarize the existing Truvari benchmark results for HG002 structural variant callsets on hg19 and hg38. The report focuses on precision, recall, F1, true positives, false positives, false negatives, SVTYPE patterns, and discordant variant categories.

2. Main metrics

Precision means how many comparison calls were supported by the truth set. Recall means how many truth variants were recovered. F1 balances precision and recall. False positives are extra calls in the comparison set. False negatives are truth variants missed by the caller.
